# ITEA-KM releases

Public manual and firmware downloads for the ITEA-KM USB/Bluetooth
keyboard-mouse appliance. The firmware source is maintained separately.

- **Flashing a new board:** [FLASHING.md](FLASHING.md) (beginner, browser-based)
- **Manual:** [MANUAL.md](MANUAL.md) (also published via GitHub Pages)
- **Firmware:** see the [Releases](../../releases) page

Firmware is flashed over the device's **COM** port with ESP-IDF.
